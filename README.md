# English Learning Bot

Telegram-бот на TypeScript для изучения английского языка с ролями ученика, репетитора и администратора. Весь рабочий интерфейс — сообщения и кнопки Telegram, без сайта и Mini App.

## Цели проекта

- интерактивные уроки и домашние задания;
- автоматическая проверка тестов;
- объяснение ошибок и типичных ловушек;
- хранение прогресса учеников;
- инструменты репетитора для создания и редактирования материалов;
- MCP-слой для генерации и анализа учебного контента.

## Структура проекта

Карта модулей и правила разработки: [организация кода](docs/architecture/code-map.md).
Все TypeScript-файлы ограничены 150 строками; `npm run quality` проверяет
форматирование, размеры файлов и типы.

- `apps/bot` — Telegram-бот для учеников и репетиторов;
- `packages/domain` — общие сущности и бизнес-правила;
- `packages/content` — учебные темы и материалы;
- `packages/mcp-server` — MCP-инструменты;
- `database` — схема и миграции базы данных;
- `docs` — документация и решения по архитектуре;
- `tests` — сценарии обучения, права доступа, проверка ответов и форматирование.

## Статус

Работающий Telegram-бот: 106 тем A1–B2, 530 упражнений, проверка по ключу, сохранение ответов и отчёт репетитору. Платные API не используются. Все исходники и тесты написаны в `.ts`; JavaScript создаётся компилятором только в игнорируемом каталоге `dist`.

Добавлены классы и группы, личные шаблоны ДЗ, назначение ученику или целому классу, проверочная с разбором после сдачи и карточки правил на картинках. [Пошаговая инструкция](docs/product/classes-and-homework.md).

В **📚 Учебнике** материал можно открывать **по школьным классам** или **по уровням A1–B2**. Это доступно каждому без вступления в группу. Для старших классов добавлены B1–B2. Внутри школьной грамматики — блоки времён, существительных, сравнений, глаголов и предложений. [Маршруты учебника и настройка классов темы](docs/product/textbook.md).

Репетитор получает одно короткое уведомление после сдачи, а полную работу открывает кнопкой. `/results` показывает список работ, `/notifications` позволяет включить тихий режим с сохранением результатов без сообщений. `/teacher` → «👥 Учебные группы» отделён от школьных классов учебника.

Рабочий бот размещён в Cloudflare Workers с постоянным SQLite-хранилищем Durable Object. Telegram работает через защищённый webhook; компьютер владельца для работы не требуется. Используется бесплатный тариф в пределах квот. [Развёртывание, перенос и резервные копии](docs/architecture/cloud.md).

## Запуск

Для разработки и облачных инструментов нужен Node.js 22+.

1. Создайте бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`.
3. Выполните `npm ci`, затем `npm run build` и `npm start`.
4. Напишите боту `/start`, затем `/whoami`. Добавьте свой числовой ID в `ADMIN_IDS` в `.env` и перезапустите процесс. Репетиторов можно назначать через `/add_teacher ID` или `TEACHER_IDS`.
5. Репетитор пишет `/invite` и передаёт команду с кодом ученику. Ученик отправляет `/join КОД`, затем `/practice`.

`npm run bot:commands` обновляет только меню команд, без повторного изменения имени и описания бота.

`npm run bot:setup` обновляет имя, описание и меню Telegram. `npm run demo` проходит урок с намеренной ошибкой в изолированной памяти; `npm run demo:send` дополнительно отправляет отчёт настроенным администраторам. Демо не создаёт учебные результаты в рабочем хранилище. Сначала администратору нужно открыть бота и нажать `/start`.

Локальный режим работает, пока запущен процесс. При установленном облачном webhook запуск локального long polling блокируется, чтобы две копии не конкурировали за сообщения. Токен не нужен для локальных тестов.

## Команды

- `/topics` — уровни и каталог с кнопками и страницами;
- `/topics A1` — темы выбранного уровня;
- `/lesson articles` — объяснение, примеры и ловушки конкретной темы;
- `/practice` — начать выбранную тему (по умолчанию Present Simple) или продолжить попытку;
- `/practice past-simple` — начать указанную тему;
- `/cancel` — отменить попытку;
- `/progress` — последние результаты;
- `/whoami` — ID и роль;
- `/invite`, `/students`, `/results` — инструменты репетитора;
- `/join КОД` — подключиться к репетитору с передачей ответов на будущие задания.
- `/editor` — справка редактора для репетитора и администратора;
- `/edit ID`, `/new ID` — открыть черновик или создать урок;
- `/preview`, `/publish`, `/discard` — посмотреть, опубликовать или закрыть черновик;
- `/history ID`, `/restore ID ВЕРСИЯ` — история и восстановление (восстановление доступно администратору);
- `/assign ID_УЧЕНИКА ID_ТЕМЫ ГГГГ-ММ-ДДTЧЧ:ММ+03:00` — домашнее задание с будущим сроком;
- `/homework` — домашние задания ученика;
- `/admin`, `/add_teacher ID`, `/remove_teacher ID` — управление для администратора.
- `/menu` — главное меню с кнопками;
- `/mode` — простая подача для детей или краткая для взрослых;
- `/teacher` — кабинет репетитора с кнопками действий.
- `/continue` — вернуться к вопросу практики или сохранённой странице объяснения.
- `/search запрос` — поиск по названию темы; кнопка «🔎 Найти тему» позволяет ввести запрос следующим сообщением.

Репетитор видит своих учеников и результаты; администратор — всех. Сейчас библиотека общая: опубликованная правка доступна всем. Изменение объяснения: `/edit articles`, затем `/theory НОВЫЙ ТЕКСТ`, `/preview`, `/publish`. Вопросы создаются пошагово через `/add_question`: тип, формулировка, варианты или допустимые ответы, ключ, объяснение. `/edit_question q1` заменяет вопрос, `/remove_question q1` удаляет его из черновика.

Редактор также работает кнопками: выберите тему, затем «🏷 Название», «📖 Правило», «💡 Примеры» или «⚠️ Ловушки» и отправьте новый текст. Остальные разделы сохраняются. Команды для отдельных разделов: `/rule`, `/examples`, `/traps`. Публикация доступна после завершения ввода. При наличии черновика `/editor` открывает его кнопки. Для выдачи роли из терминала при остановленном боте: `node --env-file=.env --import tsx scripts/grant-teacher.ts ID`; скрипт уведомляет репетитора, а если личный чат ещё недоступен, приветствие сохраняется до первого `/start`.

ДЗ фиксирует версию урока на момент назначения. Тренировка показывает объяснения после каждого ответа, проверочная — после сдачи. Назначение через `/assign` сохраняет прежний тренировочный режим, а через «📝 Мои ДЗ» режим выбирается кнопками. Просроченное задание можно сдать, а отчёт отметит опоздание. Автоматические напоминания пока не настроены.

Данные сохраняются в `data/bot.json`, путь меняется через `BOT_DATA_FILE`. Файл и `.env` исключены из Git. Храните резервную копию файла данных при остановленном боте. При аварийном завершении может остаться `data/bot.json.lock`: удалять его можно только убедившись, что процесс бота остановлен. Поддерживается один процесс на файл.

`npm run check` выполняет строгую проверку типов TypeScript, `npm run build` собирает бот, `npm test` проверяет ответы, доступ, детский сценарий, повторные нажатия, форматирование и сохранение после перезапуска. Те же проверки настроены в GitHub Actions.

## Учебная библиотека

A1: to be, местоимения, артикли, множественное число, there is / are, have got, Present Simple, предлоги времени и места, Present Continuous, can / can’t, повседневная лексика.

A2: Past Simple, Past Continuous, будущее, Present Perfect / Past Simple, сравнения, some / any / much / many, модальные глаголы, базовые сочетания с герундием и инфинитивом.

Расширение программы добавило алфавит, spelling, числа, часы, знакомство, this/that, притяжательное ’s, вопросы, порядок слов, частотность, инструкции, исчисляемость, связки, was/were, неправильные глаголы, наречия, as/as, too/enough, базовые условные предложения, неопределённые и возвратные местоимения, for/since/ago и вежливые просьбы.

Лексика и ситуации: семья, дом, еда, одежда, цвета, животные, школа, увлечения, погода, чувства, дни недели, месяцы, части тела, профессии, внешность, город, транспорт, дорога, покупки, отель, самочувствие и техника. В каталоге 47 тем A1, 41 A2, 10 B1 и 8 B2. Навигация разделена на «Первые шаги», «Грамматика», «Слова» и «Общение и письмо». Это растущая учебная библиотека, а не заявление о полном покрытии CEFR.

Расширение по тематическому каталогу Фоксфорда добавило 40 авторских уроков и 200 вопросов. B1: Past Perfect, Present Perfect Continuous, used to, пассив, косвенная речь и вопросы, relative clauses, second conditional, вопросы к подлежащему и словообразование. B2: third conditional, wish, Future Continuous / Perfect, модальные выводы, have something done, различия -ing / to и сравнение фотографий. Письмо и описание фотографий проверяются заданиями по структуре и языку; свободное сочинение, речь и загрузка фото автоматически не оцениваются.

В каждой теме — объяснение на русском, английские примеры, типичные ловушки и пять вопросов. Уровни приблизительные: это постепенно пополняемая библиотека, а не полный курс или диагностика CEFR. Время урока — ориентир. Галочка означает завершённую попытку с любым результатом. Теория и ключи копируются в попытку, чтобы последующие правки не меняли старый отчёт.

## Интерфейс для детей и взрослых

У каждой темы есть значок, короткая цель и отдельные карточки: 📖 правило, 🖼 правило на картинке, 💡 примеры, ⚠️ ловушки, ✏️ практика, 🎬 видео и источники. Внутри раздела работает переход «Дальше», есть возврат к теме и главному меню. Переход отправляет новую карточку вниз чата, а кнопки предыдущего экрана отключаются. Всплывающая подсказка говорит, где искать результат. В карточке видны тема, раздел и номер шага. Бот не управляет прокруткой клиента Telegram. Картинки правил генерируются из текста через `sharp`; репетитор может прикрепить свою фотографию схемы в редакторе.

Форматирование работает через Telegram entities: заголовки и английские примеры выделены жирным, формулы — отдельным блоком. Пример, русский перевод и пояснение разделены пустыми строками. Текст преподавателя не исполняется как HTML. При разбиении длинного сообщения сохраняются корректные UTF-16 смещения и целые эмодзи. У короткой карточки только три ряда навигации; дополнительные разделы открываются из обзора темы.

По умолчанию используется простая подача: короткое знакомство с правилом, подсказка «Запомни» и спокойное объяснение ошибки. Через `/mode` можно выбрать подачу для взрослых. Этот выбор не меняет вопросы, ключи или права пользователя и не требует даты рождения.

В практике показаны номер вопроса, индикатор прогресса и пронумерованные варианты. После завершения — краткий результат и кнопка разбора ответов по одному. Разбор доступен только самому ученику; репетитор получает отдельный полный отчёт.

Кнопка «💡 Подсказка» показывает опору по теме, не отправляя ответ за ученика. Число вопросов, где использовалась подсказка, попадает в отчёт. «🎯 Повторить только ошибки» создаёт отдельную тренировку по снимку исходных вопросов; старые ответы и оценка не переписываются. Повторение отдельно помечено в прогрессе и отчёте. «📍 Продолжить» сохраняет место чтения, а если версия урока поменялась — открывает раздел сначала.

## Подробные объяснения и источники

Первые 20 тем имеют расширенную версию 2. Последующие 86 тем добавлены как версия 1. У каждой темы есть правила, не менее шести примеров, ловушки и пять вопросов. Подсчёт правил относится к текстовым учебным блокам, а не к отдельным новым грамматическим законам.

У первоначальных 66 тем есть внешние материалы British Council; у девяти — видеостраницы LearnEnglish Kids. У 40 новых уроков — ссылки на Фоксфорд. Ссылки проверялись 8 ноября 2026 года. Если отдельная страница не открылась, показывается общий каталог с явной пометкой. Тексты и изображения издателей не копируются: внутри бота собственные объяснения и задания.

Новые объяснения написаны для проекта в `packages/content/deeper-lessons.ts`, ссылки хранятся в `packages/content/resources.ts`. Правки репетиторов из рабочего хранилища имеют приоритет над встроенным каталогом и не перезаписываются обновлением. Начатые попытки и назначенные ДЗ продолжают использовать свои снимки.

Добавление темы описано в [руководстве по материалам](docs/product/content-guide.md). При запуске каталог валидируется; тесты проходят все опубликованные темы через обработчик бота.
