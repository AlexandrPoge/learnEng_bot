# Шрифты облачных карточек

Noto Sans Regular / Bold, Noto Sans Symbols и Noto Sans Symbols 2 обеспечивают кириллицу, выделение и стрелки в PNG-карточках. Получены из официального репозитория https://github.com/notofonts/noto-fonts (`hinted/ttf/`).

Лицензия SIL Open Font License 1.1 — в `OFL.txt`. Шрифты не зависят от установленного на компьютере пользователя набора.
