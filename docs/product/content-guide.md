# Добавление учебной темы

Материалы находятся в `packages/content`. Каталог `catalog.mjs` — единственная точка подключения опубликованных тем к боту. `a1.mjs` и `a2.mjs` содержат новые темы; исторический `present-simple.mjs` сохранён, чтобы стабильный ID темы не изменился.

`lesson-builder.mjs` предоставляет `lesson`, `choice` и `gap`. Тема содержит стабильный короткий ID латиницей, название, приблизительный уровень, версию, теорию и вопросы. Теория собирается из правил, примеров и ловушек. Категория — `grammar` или `vocabulary`, время — приблизительная оценка. Английские примеры должны быть понятны из русскоязычного объяснения и контекста.

Для вопроса с выбором нужен ровно один правильный вариант и объяснение. Для пропуска нужны все допустимые ответы в `accepted`. Не используйте строгую проверку по строке для свободного перевода или сочинения: без ручной проверки это может отклонить корректную формулировку.

В заданиях следует избегать неоднозначности: если возможны несколько времён или артиклей, уточните контекст или замените упражнение. Нормализация игнорирует регистр, лишние пробелы и конечную пунктуацию, но не исправляет грамматику. Правило должно объяснять ошибки, а не только указывать ключ.

При изменении содержания увеличьте `version`. Снимки уже начатых и завершённых попыток остаются прежними. Стабильный `id` сохраняет историю прохождения темы. Метка «пройдено» означает завершение, не освоение.

Перед коммитом выполните `npm run check` и `npm test`. Валидатор ловит повторные ID и некорректные ключи, интеграционный тест проходит каждую опубликованную тему. Смысл и педагогическое качество заданий проверяются редактором: автоматическая проверка структуры не заменяет просмотр репетитором.

Картинки пока не подключены. На этапе медиа к примерам добавятся Telegram file_id, текстовое описание и резервный оригинал. Для произношения и аудирования нужны собственные задания, не просто картинка к грамматическому правилу.
