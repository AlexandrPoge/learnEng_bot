# Учебник: школьные классы и уровни

Основная кнопка ученика — **📚 Учебник** (`/textbook`). В ней два независимых способа найти материал:

- **🏫 По школьным классам**: 1–11 класс → раздел → тема → правило / картинка / примеры / ловушки / упражнения.
- **🌱 По уровням A1–A2**: уровень → темы и разделы курса → тот же урок.

Для просмотра учебника не нужно создавать группу, подключаться к репетитору или вступать по коду. Номер класса не означает уровень CEFR. У каждой темы сохранён её собственный A1/A2.

Школьные подборки — авторский порядок текущих 66 тем; они не заявляют соответствия конкретной государственной программе или учебнику. Для 1–7 классов выбраны темы для знакомства, изучения и повторения. Для 8–11 явно показано **повторение базы A1–A2**, а не полный материал старших классов. Уровни B1–C2 сейчас не добавляются. Одна тема может быть в нескольких классах; ответы и прогресс не дублируются из-за выбора другого маршрута.

`packages/content/school.ts` хранит подборки и порядок. Темы подтягиваются из текущего общего каталога, включая опубликованные правки преподавателя. `schoolGrades` в уроке переопределяет стандартную подборку: `[3, 4]` показывает тему в 3 и 4 классах, `[]` оставляет её только в уровнях. Если поле не задано, применяется стандартный маршрут.

Репетитор открывает урок в редакторе → **🏫 Школьные классы** → отправляет `3, 4, 5` → публикует. Команда `/school_grades 0` убирает тему из всех школьных подборок. Начатые попытки и выданные ДЗ сохраняют прежние снимки. Личные шаблоны ДЗ не включаются в публичный учебник.

В карточке темы и текстовом объяснении виден выбранный школьный класс. Возврат сохраняет раздел и страницу. Переход в уровни или глобальный поиск очищает школьный маршрут. `/school` открывает выбор классов, `/school 4` — разделы 4 класса. Прежняя `/topics` остаётся входом в уровни.

Учебные группы с участниками и назначениями находятся в кабинете репетитора под кнопкой **👥 Учебные группы** (`/classes`). У ученика этот раздел доступен через меню команд, а учебник открывается без группы. Прежние кнопки «Мои классы» продолжают работать как совместимые ссылки на группы.
